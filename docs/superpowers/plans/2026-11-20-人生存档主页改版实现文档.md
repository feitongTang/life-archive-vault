# 人生存档主页改版实现文档

2026-11-20 · 待确认

本次改版面向 Obsidian 中实际打开的「人生存档」插件首页。首页展示近期整体状态和日常记录入口，并通过「当前章节」进入人生地图。用「自我修行」和「跳槽」验证这套结构，再用可追溯的月度复盘填充角色面板。

设计依据包括 [[人生存档主页设计方案]]、[[第二大脑插件技术方案]]、[[AI 第二大脑方案]] 和 [[重大决策模块设计方案]]。本版将主页原案的 RPG 角色面板和六个月趋势纳入交付，沿用技术评审稿的月度摘要、来源追溯和本地 Markdown 存储。本文是评审稿，确认后进入开发。

## 1. 首页信息与交互

| 区域 | 展示与操作 |
| --- | --- |
| 页首 | 「人生存档」、最近一期可读的 AI 复盘月份及状态。点月份打开该期复盘。保留今日日记、写篇思想和 GitHub 同步入口。 |
| 角色面板 | 并排展示精力、情绪、专注和方向感。每张卡包含当月档位、与上一自然月的变化、近六个月趋势和依据入口。趋势收在对应卡内。 |
| 记录日历 | 桌面位于角色面板下方，与月度摘要和关键词并排。保留日期详情、习惯筛选与打卡、周号、月／季／年切换及已有笔记标识。打开已有笔记，缺失时沿用现有模板创建。 |
| 月度摘要与关键词 | 一段简短摘要，最多三个关键词，每项附一句具体观察。点击可到该项复盘依据，再打开原文。历月复盘入口按月份倒序浏览。 |
| 当前章节 | 展示当前章节、贯穿该阶段的主线、值得跟进的支线，以及已有的待复盘决策。提供进入人生地图和打开对应任务的入口。 |
| 近期记录 | 近期思想和周期笔记放在下方浏览区，保留原有列表与查看全部操作。 |

窄分栏按页首、属性、日历、摘要与关键词、当前章节、近期记录排列，属性卡随宽度换行。趋势同时提供文字状态，操作可用键盘完成，沿用 Obsidian 明暗主题。日历中的月笔记是用户复盘，页首月份和属性依据指向 AI 月度复盘，两篇笔记可以互相链接。

## 2. 角色属性和趋势

沿用原案的 1–5 档口径。精力看疲惫、恢复和负荷，情绪看波动及恢复，专注看能否持续投入重要事项，方向感看优先级和关键取舍。评分依据随月份保存，至少包括一句解释、原文链接和口径版本。评分基于当期材料，按独立事件核对证据，用户可以在复盘中补充或纠正。

| 数据状态 | 首页表现 |
| --- | --- |
| 冷启动，没有可读 AI 月度复盘 | 四张卡、趋势位置和摘要区照常显示。卡片显示「待首次复盘」，档位用「—」，趋势显示六个自然月的月份轴和「暂无趋势」。此时六个月以最近一个已结束的自然月为末月。 |
| 已有复盘，某项资料不足 | 对应卡显示「资料不足」，档位留空。其他有依据的属性正常显示。缺失月在趋势中断开。 |
| 某项仅有一个月可评分 | 显示真实档位和单个趋势点，环比显示「暂无对比」。 |
| 有多月可比评分 | 显示最近一期档位。与紧邻的上一自然月比较，呈现「上升」「持平」或「下降」。只连接连续且口径一致的评分，跨缺失月份和评分版本时断开。 |
| 最新月份尚未生成或无法读取 | 有历史复盘时继续展示最近一期可读结果，明确标出实际月份。已知读取失败时提供对应状态。无历史结果时展示冷启动或读取失败状态。 |

趋势随最近一期可读复盘定位，显示该月及往前五个自然月，按上海时区跨年计算。四张卡共享月份轴。无数据状态只用于界面展示，0 分、示例分数和演示曲线均不进入真实记录。关键词同样按实际证据数量展示，缺少依据时显示「暂无有来源的关键词」。

## 3. 当前章节、人生地图和决策

- **章节**是一段人生经历。首次展示以「职业发展与工作轨迹」作为当前章节的暂用名称，起止日期等你提供后再录入。无日期时按当前章节展示。
- **主线**是贯穿多个章节的「自我修行」。**支线**先用「跳槽」，关联当前章节和主线。考公、考编的合理性与可行性是支线正在探索的问题。
- **人生地图**是首页打开的 Obsidian Canvas 二级页面。以章节为时间脉络，连接主线、支线和已确认决策。现有「自我修行」「跳槽」笔记作为可复用的原文入口。地图上的节点可以进入笔记，查看任务推进、材料和复盘。
- **从支线到决策**沿用重大决策原案。任务推进和中期复盘保留当时的选项、依据与未知项。结束复盘可以提出零个或多个候选，每项附来源，经用户确认后才归档。首页可链接待跟进档案，人生地图上的决策节点和结束复盘回链指向同一篇正式笔记。长期主线能否在阶段复盘提前归档，仍是待确认项。

本次交付首页和地图的入口，以及主线、支线、复盘、已有决策的链接关系。首版使用 Obsidian 原生笔记和 Canvas 编辑维护内容，插件负责读取和导航。决策候选自动提取和自动归档工作流另行确认。实际走查可以用「跳槽」支线，决策节点用隔离测试库中的样例验证。

## 4. 数据与代码落点

| 内容 | 实现约定 |
| --- | --- |
| 月度复盘 | 约定读取 `复盘/AI/YYYY-MM.md`。月份由路径确定。沿用可读的「摘要」「关键词」正文，增加「角色属性」区，按固定四项读取档位、理由、口径版本与来源。缺失区段允许旧复盘仍显示摘要和关键词。对越界档位、失效来源或无法解析的属性作局部降级。 |
| 当前章节与地图 | 在库内增加可编辑的章节入口，保存章节名称、选填起止日期及对应任务链接。插件设置可选择当前章节和 Canvas 文件。地图节点和首页直接引用库内文件，同一篇笔记只保存一份。文件移走或链接失效时显示可恢复的空状态。 |
| 数据读取与刷新 | 在 `.life-archive-plugin/src/core/` 增加月度复盘与章节读取模型，复用现有 Vault 访问。由 `src/main.ts` 将相关复盘、章节和地图改动加入现有刷新事件，覆盖创建、修改、重命名与删除。保持日历选中日期、筛选、焦点和滚动位置。 |
| 界面 | `src/obsidian/home-view.ts` 组装真实数据并处理打开笔记、Canvas 和复盘索引的动作。`src/ui/home.ts` 重排首页，将属性和摘要渲染放在同职责的独立文件中，沿用 `styles.css` 和现有日历渲染。 |
| 数据生成 | 已安装首页当前没有月度摘要和评分的读取入口。这次先实现从约定 Markdown 展示完整状态，以隔离测试数据验证有效月份。AI 自动运行、调度和写回可沿用技术方案单独接入，首页可在离线和无复盘资料时使用。 |

## 5. 实施与验收顺序

1. **复盘数据和状态。** 用空库、旧复盘、单月评分、跨年缺月、评分版本变化和无效档位覆盖读取与趋势计算。验证最新不可读时能回退，摘要和关键词仍可单独展示。
2. **重排首页。** 检查冷启动时四项属性和趋势位置齐全。加入真实格式的测试复盘后，逐项核对月份、评分、环比、缺月断点及证据链接。回归测试日历、习惯、周期笔记、思想和同步入口，检查窄分栏、明暗主题及键盘操作。
3. **接通当前章节和 Canvas。** 从首页打开「跳槽」及人生地图，分别回到「自我修行」和当前章节。验证未配置、文件重命名、断链和章节未填写日期时的表现。用隔离库中的样例，从结束复盘与地图打开同一篇正式决策，再回到关键原文。
4. **在测试库验收。** 在插件源码目录运行 `npm test` 和 `npm run build`，随后在桌面 Obsidian 中走查新旧数据。冷启动和样例复盘分别检查，确认示例数据没有进入真实库，再按获准范围安装。

待确认的实现选择包括当前章节名称和时间、是否采用「先接入已有月度复盘，自动生成随后接入」的交付顺序，以及长期主线的阶段归档时点。支线探索可以在首页和地图确认后继续。
